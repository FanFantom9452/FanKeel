# Sources

The evidence ledger. `docs/improvement-brief.md` §2.4 D1 described SEPIA's
own evidence ledger — one stable ID per measurement, seven columns, and a
reverse-index column so that changing a figure says which pages have to
change with it. This page is that mechanism for fankeel's own dated reports.

Every row below is one of the fourteen dated reports at the top level of
`docs/reports/`. The 47 files under `docs/reports/evidence/` are the raw
`claude -p --output-format json` output and diffs behind three of those
reports, not reports of their own, so they carry no row — a row's Link column
points at the report, and the report itself points at its evidence directory
when it has one.

**Read the Scope column before quoting a figure.** It says what the
measurement does not cover, which is what stops one row from reading as
contradicting another — the clearest case is the three-way split on
dispatch-vs-inline residue (9.2× / 2.55× / 1.5×), which is one gradient, not
three disagreeing numbers, once each row's Scope says which variable it held
fixed.
