## the footnote that makes Fable 5.1 the exception and Fable 5 not

  "Cache hits and refreshes on Claude Fable 5.1 and Claude Mythos 5.1 are priced
  at 0.025x the base input price. All other models use the standard 0.1x
  multiplier."

So Fable 5.1's $0.25 against a $10 input is 0.025x, and Fable 5's $1 against the
same $10 input is 0.1x: the exception is the version, not the family. That is the
distinction `tests/prices.test.js`'s ratio test encodes.

## the cache multipliers, quoted

  | 5-minute cache write | 1.25x base input price |
  | 1-hour cache write   | 2x base input price    |
  | Cache read (hit)     | 0.1x base input price (0.025x on Claude Fable 5.1 and Claude Mythos 5.1) |

## what is deliberately NOT in lib/prices.js, and why

Claude Mythos 5 and Claude Mythos 5.1 are on the published table, both marked
"limited availability". They are absent from `lib/prices.js` for the same reason
every other published row is absent: the table holds the ids this machine's
transcripts carry. Nothing here has scanned for a Mythos id and found none — the
claim is only that none was found while looking for unpriced ids, which is a
weaker statement, and it is the one being made.

Opus 4.7, 4.6, 4.5, Sonnet 4.6, 4.5 and the retired rows are absent on the same
grounds.

## one line worth recording, not acted on

  "Claude 4.6 and later models and Claude Mythos Preview include the full 1M
