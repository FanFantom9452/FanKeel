# 介面語言 ui.lang Implementation Plan

**Goal:** one UI language for the station page, the Pane mod and the band mod, set in the station, followed live.
**Architecture:** the profile gets two keys: `model.lang` (the old `language`, the language stage agents write reports and gates in; an old `language` in a file is still read as it) and `ui.lang` (`zh` | `en`, unset = today). The station's globe menu also posts `ui.lang` to the machine profile, and the page reads `profiles.machine` before `localStorage` and the browser. The mod gets `hooks/pane-lang.ts`, a zh/en word table plus a reader of the machine profile's `ui.lang`; `hooks/pane.ts` reads it every tick and passes `lang` into the band, the Pane and the Desktop drawings, which look their words up instead of writing Chinese.
**Tech Stack:** Node `>=22.5`, no dependencies, `node --test`; `hooks/*.ts` run under Claude Code's engine and under node's type stripping in the tests (no `tsc`); the station page is ES5 in a browser.
**Spec:** 2026-10-22-ui-lang-design.md

// The file reads langAt needs, as plain functions: the engine refuses $ passed to an imported function.
export type LangIo = {

  read(path: string): Promise<string>

// The machine profile's ui.lang (lib/profile.js machineFile: <configDir>/fankeel/profile.json),
// read on every call so a pick on the station shows on the next tick. A missing
// file, any other value, or a file that does not parse is zh.
export async function langAt(io: LangIo, configDir: string): Promise<Lang> {
  if (!configDir) return 'zh'
  const file = `${configDir.replace(/[\\/]+$/, '')}/fankeel/profile.json`
  try {
    if (!(await io.exists(file))) return 'zh'
    const v = (JSON.parse(String(await io.read(file)).replace(/^\uFEFF/, '')) as Record<string, unknown>)['ui.lang']
    return typeof v === 'string' && v.trim().toLowerCase() === 'en' ? 'en' : 'zh'
  } catch (err) {

    return 'zh'
  }
