## Global Constraints

- No dependency may be added: `package.json` declares none and every script uses the standard library only.

- Skill byte caps are asserted in `tests/skill-size.test.js:12-13` (fankeel 78000, fankeel-build 49000, every other skill 24000); `node scripts/skills-check.js` must stay green.
- Every reference page carries frontmatter (`status`, `last_verified`, `source_of_truth`) and `node scripts/docs-check.js` must stay green; a markdown file outside every `.fankeel/docs.json` bucket is reported unfiled.
- Commit subjects are conventional (`fix:`, `docs:`, `feat:`, `chore:`), body ends with the Co-Authored-By line.
- TODO entries are closed at land with `todo.js done`, never by a build task.
- `.fankeel/map.md`: 1024 markdown files, 4 planned (this design among them), 28 undeclared — no current page contradicts the design; `docs/90-agent/reference/subagents.md` gains the foreground-reader reason (Task 4).

The protocol points the implementer must keep:
- `touch` checks and writes through **one descriptor** (`openSync(file, 'r+')`). A waiter that renames the lock aside after the check moves this inode with it, so the write never lands in a lock a different run has since created at the path. A truncate-then-write window reads to a waiter as unparsed with a fresh mtime, which it already waits on (`FRESH_MS`).
- `touch` writes only when the record's `pid` and `at` are both the holder's own; a lock already taken over is left alone.
- A refreshed `out` changes the record, so a waiter's `clearStale` that judged an older copy finds the moved-aside file different and links it back — the live holder keeps the lock. That path exists and is tested (`clearStale removes the holder it was given...`); do not change `clearStale`.
- `at` is stamped on each `wx` attempt, not once before the wait: today a run that waited an hour for the lock is born already older than `MAX_AGE_MS`, and the first waiter after it takes the lock from a live suite.
- A holder that never prints for 60 min is still judged stale: `out` only extends life while there is output. A record with no `out`, or a non-number `out`, is judged on `at` alone, as now — an older fankeel's lock reads the same.

// Writes `out: now` into the lock while it is still the one `mine` ({ pid, at })
// names. The check and the write go through one descriptor: a waiter that moves
// the file aside after the check moves this inode with it, so the write never
// lands in a lock another run has since created at the path. Best effort — a
// lock gone or taken over is false, never a throw.
function touch(file, mine, now = Date.now()) {
    let fd;
    try { fd = fs.openSync(file, 'r+'); } catch (e) { return false; }
    try {
        const h = JSON.parse(fs.readFileSync(fd, 'utf8'));
        if (!h || h.pid !== mine.pid || h.at !== mine.at) return false;
        const text = JSON.stringify({ ...h, out: now }) + '\n';
        fs.ftruncateSync(fd, 0);
        fs.writeSync(fd, text, 0);
        return true;
    } catch (e) {
        return false;
    } finally {
        fs.closeSync(fd);
    }
}

// The holder's output hook: called on every chunk its suite prints, it touches
// the lock at most once per everyMs, counted from the lock's own `at`.
function refresher(file, mine, everyMs = REFRESH_MS) {
    let last = Date.parse(mine.at);
    return (now = Date.now()) => {
        if (now - last < everyMs) return false;
        last = now;
        return touch(file, mine, now);
    };
}

// Two memory files on one subject are a merge the slimmer proposes. The
// measure is the Jaccard ratio of their word sets — name, description and
// body; each Han character one word, any other run of three or more letters
// or digits one word, so `the`, `run` and `中` count and `it`, `on` do not.
// 0.5, because on 2026-10-19 the six pairs of this project's four memory
// files ranged 0.067-0.165 (the top pair cross-links with [[...]]), and one
// fact said twice in different words measured 0.72. A pair is listed, never a
// failing finding, so a false one costs a line.
const SIMILAR = 0.5;
const FRONT = /^---\r?\n[\s\S]*?\r?\n---\r?(?:\n|$)/;
const WORD = /\p{Script=Han}|[\p{L}\p{N}]{3,}/gu;

// `[[name]]`, `[[name|label]]`, `[[name#part]]` — how memory files cite one
// another. docs-check.js's LINK wants `](` and never sees these.
const WIKI = /\[\[([^\]\n|#]+)(?:[|#][^\]\n]*)?\]\]/g;

function wikiLinks(text) {
    const out = [];
    WIKI.lastIndex = 0;
    let m;
    while ((m = WIKI.exec(String(text))) !== null) out.push(m[1].trim());
    return out;
}

function wordSet(text) {
    const fm = docs.frontmatter(text) || {};
    const body = String(text).replace(FRONT, '');
    return new Set([fm.name || '', fm.description || '', body].join(' ').toLowerCase().match(WORD) || []);
}

function jaccard(a, b) {
    if (!a.size && !b.size) return 0;
    let both = 0;
    for (const w of a) if (b.has(w)) both++;
    return both / (a.size + b.size - both);
}

function similarPairs(files, threshold) {
    const out = [];
    for (let i = 0; i < files.length; i++) {
        for (let j = i + 1; j < files.length; j++) {
            const ratio = jaccard(files[i].words, files[j].words);
            if (ratio < threshold) continue;
            out.push({
                tag: 'similar', name: files[i].name, other: files[j].name, ratio,
                what: files[i].name + ' and ' + files[j].name + ' share ' + Math.round(ratio * 100) + '% of their words',
            });
        }
    }
    return out;
}

```js
#!/usr/bin/env node
'use strict';
// scripts/verify-map.js: the verification map's lint, and the feature files a
// change reaches.
//
//   node scripts/verify-map.js [--root <dir>]
//   node scripts/verify-map.js [--root <dir>] --range <a>..<b>
//
// `.fankeel/verify/README.md` states the format this reads. The first form
// prints one `warn:` line per problem in `.fankeel/verify/<feature>.md` and a
// count, and exits 0 whatever it found: a first slice that refused on a prose
// map would be a gate nobody decided on. The second prints the feature files
// whose globs match a path `git diff --name-only --relative <a>..<b>` names,
// one per line, or `none`. The match is `pagesTouched` in lib/shots.js run on
// the features' globs, so a glob means here what it means in render.json, and
// a `kind: page` file's `render:` stands for the `src` of the render.json
// pages it names rather than a second copy of them.
const fs = require('node:fs');
const path = require('node:path');
const { execFileSync } = require('node:child_process');
const { parseArgsOrExit } = require('../lib/cli.js');
const { frontmatter } = require('../lib/docs.js');
const { pagesTouched, loadTargets } = require('../lib/shots.js');
const { trackedFiles } = require('../lib/tracked.js');

const REL = '.fankeel/verify';
const KINDS = ['page', 'cli', 'hook'];
const STATUSES = ['clean', 'changed', 'blocked'];
const SECTIONS = ['Sub-features', 'Reach', 'Drive', 'Gotchas', 'Doctor'];
const DATE = /^\d{4}-\d{2}-\d{2}$/;
const EXIT_CODE = /\bexits?\s+\d+/;

// `[a, b]`, or one bare value: the list shape lib/docs.js's reader hands back
// as a string. Null when the key is absent, so "absent" and "empty" differ.
function list(value) {
    if (value === undefined) return null;
    return String(value).trim().replace(/^\[/, '').replace(/\]$/, '')
        .split(',').map((x) => x.trim().replace(/^["']|["']$/g, '')).filter(Boolean);
}

// Every `## ` heading outside a fence, with the text under it.
function sections(text) {
    const out = new Map();
    let name = null;
    let fence = false;
    for (const line of String(text).split(/\r?\n/)) {
        if (/^(```|~~~)/.test(line)) fence = !fence;
        const h = fence ? null : /^##\s+(.+?)\s*$/.exec(line);
        if (h) {
            name = h[1];
            out.set(name, '');
        } else if (name !== null) {
            out.set(name, out.get(name) + line + '\n');
        }
    }
    return out;
}

// The feature files, sorted by name. README.md is the format, not a feature.
function featureFiles(root) {
    let names;
    try {
        names = fs.readdirSync(path.join(root, REL));
    } catch (e) {
        return [];
    }
    return names.filter((n) => n.endsWith('.md') && n !== 'README.md').sort();
}

function renderTargets(root) {
    return loadTargets(path.join(root, '.fankeel', 'render.json'));
}

// The globs a feature stands for: its own `src`, then the `src` of each
// render.json page its `render:` names.
function globsOf(front, targets) {
    const out = (list(front.src) || []).slice();
    for (const page of list(front.render) || []) {
        const globs = targets && targets.src.get(page);
        if (globs) out.push(...globs);
    }
    return out;
}

function lint(root) {
    const files = featureFiles(root);
    const warnings = [];
    const loaded = files.length ? renderTargets(root) : null;
    const targets = loaded && loaded.targets ? loaded.targets : null;
    if (loaded && loaded.refusal) warnings.push('.fankeel/render.json: ' + loaded.refusal);
    let tracked = null;
    for (const name of files) {
        const rel = REL + '/' + name;
        const warn = (what) => warnings.push(rel + ': ' + what);
        const text = fs.readFileSync(path.join(root, REL, name), 'utf8');
        const front = frontmatter(text);
        if (!front) {
            warn('no frontmatter');
            continue;
        }
        const feature = name.slice(0, -'.md'.length);
        if (front.feature !== feature) warn('`feature` is "' + (front.feature || '') + '" and the file name says "' + feature + '"');
        if (!KINDS.includes(front.kind)) warn('`kind` is "' + (front.kind || '') + '", not one of ' + KINDS.join(', '));
        if (!STATUSES.includes(front.status)) warn('`status` is "' + (front.status || '') + '", not one of ' + STATUSES.join(', '));
        if (!DATE.test(front.last_checked || '')) warn('`last_checked` is "' + (front.last_checked || '') + '", not a YYYY-MM-DD date');
        const own = list(front.src) || [];
        const pages = list(front.render) || [];
        if (pages.length && front.kind !== 'page') warn('`render` belongs to a `kind: page` file only');
        if (front.kind === 'page' && !own.length && !pages.length) warn('a page needs `render` naming render.json pages, or `src` where render.json does not declare it');
        if ((front.kind === 'cli' || front.kind === 'hook') && !own.length) warn('a ' + front.kind + ' needs `src`');
        for (const page of pages) {
            if (!targets) warn('`render` names "' + page + '" and there is no readable .fankeel/render.json');
            else if (!targets.pages.has(page)) warn('`render` names "' + page + '", which .fankeel/render.json does not declare');
            else if (!targets.src.has(page)) warn('render.json page "' + page + '" has no `src`, so no change reaches this file through it');
        }
        if (own.length) {
            if (tracked === null) {
                const result = trackedFiles(root);
                tracked = result ? result.files.map((f) => f.replace(/\\/g, '/')) : [];
            }
            for (const glob of own) {
                if (!tracked.some((f) => path.posix.matchesGlob(f, glob))) warn('`src` glob ' + glob + ' matches no file');
            }
        }
        const body = sections(text);
        for (const s of SECTIONS) if (!body.has(s)) warn('no `## ' + s + '` section');
        if ((front.kind === 'cli' || front.kind === 'hook') && body.has('Doctor') && !EXIT_CODE.test(body.get('Doctor'))) {
            warn('a ' + front.kind + "'s `## Doctor` names no exit code to check (`<command>` exits 0)");
        }
    }
    return { files: files.map((n) => REL + '/' + n), warnings };
}

// The feature files whose globs match any of `paths` (relative to `root`).
function touched(root, paths) {
    const loaded = renderTargets(root);
    const targets = loaded && loaded.targets ? loaded.targets : null;
    const src = new Map();
    for (const name of featureFiles(root)) {
        const front = frontmatter(fs.readFileSync(path.join(root, REL, name), 'utf8'));
        const globs = front ? globsOf(front, targets) : [];
        if (globs.length) src.set(REL + '/' + name, globs);
    }
    return pagesTouched({ src }, paths);
}

function main(argv) {
    const { values } = parseArgsOrExit('verify-map', argv, { root: { type: 'string' }, range: { type: 'string' } });
    const root = path.resolve(values.root || process.cwd());
    if (values.range !== undefined) {
        let changed;
        try {
            changed = execFileSync('git', ['diff', '--name-only', '--relative', values.range],
                { cwd: root, encoding: 'utf8', stdio: ['ignore', 'pipe', 'ignore'] }).split(/\r?\n/).filter(Boolean);
        } catch (e) {
            return 'verify-map: git could not read ' + values.range;
        }
        const hit = touched(root, changed);
        return hit.length ? hit.join('\n') : 'none';
    }
    const { files, warnings } = lint(root);
    const plural = (n, word) => n + ' ' + word + (n === 1 ? '' : 's');
    return warnings.map((w) => 'warn: ' + w)
        .concat('verify-map: ' + plural(files.length, 'feature file') + ', ' + plural(warnings.length, 'warning'))
        .join('\n');
}

if (require.main === module) process.stdout.write(main(process.argv.slice(2)) + '\n');

module.exports = { lint, touched, sections, list, main, KINDS, STATUSES, SECTIONS };
```

# The verification map

`.fankeel/render.json` says which pages to photograph. This directory says how a person reaches a feature, drives it, and what misleads them along the way. Each feature has one file: a short header that a script reads, then prose. [station.md](station.md) is the worked example.

## A feature file

`.fankeel/verify/<feature>.md`, named after the feature. Its frontmatter:

| key | what it holds |
|---|---|
| `feature` | the file name without `.md` |
| `kind` | `page` for something a browser shows, `cli` for a command, `hook` for a Claude Code hook |
| `src` | the globs of the files the feature is made of, written `[a, b]`, relative to the repository root and matched the way render.json's `src` is |
| `render` | `page` only: the render.json page names this feature covers. Their `src` counts as this file's `src`, so a page render.json already declares is not declared twice. Leave `src` off when `render` covers it, and give `src` when render.json does not declare the page |
| `last_checked` | the day a reader last checked the file against its source, `YYYY-MM-DD` |
| `status` | the result of that check: `clean`, `changed` or `blocked` |

The body has five `##` sections. Every one is required:

- **Sub-features**: what the feature does, one bullet each, so a verifier can say which ones a change reached.
- **Reach**: the command or url that gets to the feature, and what it prints.
- **Drive**: numbered steps, each saying what it must show. A verifier's evidence row cites the file and the step number.
- **Gotchas**: what can make a drive pass or fail for the wrong reason.
- **Doctor**: the checks that decide whether driving is worth doing at all. When a check fails, the row is `blocked`, not a pass. For `cli` and `hook` the Doctor is an exit-code check: the command, followed by `exits 0` or whatever code it should exit with.

## Evidence and cleanup

Evidence goes under `.fankeel/build/task-<started>/verify/<feature>/`: screenshots and command output. Cleanup stops whatever Reach started and deletes the temporary directories it made. It never deletes evidence. Evidence is kept and moved, never cleaned up.

## Who reads it

- verify: `node scripts/verify-map.js --range <a>..<b>` prints the feature files whose globs the change matches, matched through `pagesTouched()` in `lib/shots.js`. The verifier runs each file's Doctor, then its Drive.
- audit: one reader per file checks it against its source and answers `clean`, `changed` or `blocked`.
