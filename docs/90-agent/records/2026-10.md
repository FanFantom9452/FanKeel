## 2026-10-19 每個任務 land 時寫六欄完成紀錄，監控站卡片與最後訊息都用它

- 要求：每個任務在 land 時寫一份六欄完成紀錄，不管有沒有 TODO；監控站卡片和最後訊息都用它。
- 做了什麼：
  - land 時用 record.js 寫一份六欄紀錄，缺一欄或句子太長就拒收，花費由程式從對話紀錄算出。
  - 紀錄同時存進任務登記和每月一份的紀錄檔，每份有自己的錨點，可以從 TODO 連過去。
  - 監控站的清單、詳細面板和 session 頁都顯示同一份六欄紀錄，沒有紀錄的 session 會說明原因。
  - land 的最後一則訊息就是這六欄，不再另寫一段摘要。
- 為什麼這樣做：紀錄由一支程式寫、一處存放，監控站和訊息都讀同一份，避免兩邊說法不同。花費改在 land 當下從對話紀錄算，因為登記裡平時沒有金額；代價是 land 前要先讀一次對話紀錄。
- 驗過・沒驗過：完整測試 4759 個全過；在暫存目錄實跑過寫入、拒收和監控站逐欄比對。監控站畫面沒在瀏覽器裡和草稿比對過；「land 先寫紀錄再收尾」的順序只靠技能文字，沒有程式擋。
- 花費：$33.67，3 小時 28 分，58 個 agent（主 session opus-5-5，agent 用 sonnet-5-5、opus-5-5、fable-5-1）。
- 還剩什麼：寫入登記失敗的路徑沒有測試。判官建議拿掉四處重複的測試斷言，還沒做。答「要離開」時不停手那條 TODO 還開著。
