## Global Constraints

- Zero runtime dependencies, no build step: plain CommonJS, `'use strict'`, 4-space indent in `lib/` and `scripts/`, 2-space in `tests/` (as the files already are).
- `tests/*.test.js` run with `node --test`. Every exported name needs an importer, and a new file has to be staged (`git add`) before `tests/source.test.js` can see it (map).
- An implementer runs only its own test command, never the full suite; build's parent runs `node scripts/suite.js --fast`.
- `.fankeel/` is `STATE_DIR` (`lib/docs.js:117`): runtime and settings, never a document's claim.
- `tests/render.test.js:363-372` asserts the build skeleton in `docs/01-guide/concepts.md:51-59` verbatim — that block is not touched.
- Guide pages (`docs/01-guide/`) are 繁體中文, `你`-address, short sentences; code identifiers stay in English.
- Release: land bumps the version — a feature here, so minor — and the plugin is updated after it lands (memory: release on every change).

## Risks

- Node's coverage table nests files under directory rows by indent, one space a level (seen on v24.21.0) — Task 3 — its parser test carries that exact table, so a different layout fails the test rather than recording nothing.
- `lib/map.js` `orientation()` returns `[]` before any section when the tree has no `require` edges — Task 2 — the test fixture carries requires, and the design asks for `largest:` after `most required:`, which only exists inside that branch.

// The longest files by line count — where a reader's time goes, which
// "most required" does not say. A file holding a NUL byte is binary.
function largest(root, files, n = 5) {
    const rows = [];
    for (const rel of files) {
        const text = readText(path.join(root, rel));
        if (text === null || text.includes('\0')) continue;
        rows.push([rel, text.split('\n').length - 1]);
    }
    return rows
        .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))
        .slice(0, n)
        .map(([rel, lines]) => rel + ' — ' + lines + ' lines');
}
```

// node --test's coverage table as { file: line % }. Files sit under their
// directory rows, one space of indent a level, and a directory row is blank.
// Null when the run printed no table.
function parseCoverage(tap) {
    const lines = String(tap || '').split(/\r?\n/);
    const start = lines.findIndex((l) => l.startsWith('# start of coverage report'));
    if (start === -1) return null;
    const out = {};
    const stack = [];
    for (const l of lines.slice(start + 1)) {
        if (l.startsWith('# end of coverage report')) break;
        const m = /^# ( *)([^|]+?)\s*\|\s*([\d.]*)\s*\|/.exec(l);
        if (!m || m[2] === 'file' || m[2] === 'all files') continue;
        stack.length = m[1].length;
        stack[m[1].length] = m[2];
        if (m[3]) out[stack.join('/')] = Number(m[3]);
    }
    return out;
}

// The flags that make node --test measure these files and only these.
function coverageFlags(files) {
    if (!files || !files.length) return '';
    return ' --experimental-test-coverage' + files.map((f) => ' --test-coverage-include=' + JSON.stringify(f)).join('');
}

// What a task touched that coverage can measure: its JavaScript, not its tests.
function coverageFiles(claims) {
    return (claims || []).filter((p) => /\.[cm]?js$/.test(p) && !p.startsWith('tests/'));
}
```
