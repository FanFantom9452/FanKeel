# The Patrol Takes Ready Implementation Plan

**Goal:** `/fankeel` offers no `## Ready` option; the patrol, `TODO 全表盤點`, walks every heading and builds Ready on the fixed route `survey,plan,build,verify,land`.
**Architecture:** Four text surfaces carry the old two-option shape: the INIT rule in `lib/stages.js`, the `todo:` block `scripts/orient.js` prints, the patrol sections of three skills, and four documents. Each is rewritten in place, with the test that pins it. No new module, no new field.
**Tech Stack:** Node, CommonJS, `node --test` (`package.json` `"test": "node --test"`), no dependencies.
**Spec:** [2026-09-30-patrol-takes-ready-design.md](2026-09-30-patrol-takes-ready-design.md)

## Global Constraints

- No dependencies may be added: `package.json` has no `dependencies` block.
- The injected block is capped at 2400 characters (`lib/render.js:573`, `BLOCK_CAP = 2400`). The new INIT sentence must be no longer than the one it replaces.
- Every INIT rule is longer than 20 characters, and there are at least 3 of them (`tests/stages.test.js:631-632`).
- `TODO.md` is generated by `node scripts/todo.js index` and never edited by hand; the entry files live in `docs/90-agent/todo/`.
- Decision, report and archive pages are write-once (`docs.json` roles). Do not edit any page under `docs/03-decisions/`, `docs/90-agent/reports/` or `docs/99-archive/`.
- Prose in `docs/01-guide/getting-started.md` is 繁體中文; everything else is English. Name code concepts in code.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- An implementer runs only its own test file, never the full suite. The parent runs `npm test` before committing a group.

## Risks
- The INIT sentence grows past the old one and pushes the init block toward the 2400 cap — Task 1 — Step 1 prints both lengths before any edit.
- A test elsewhere pins the old `patrol:` wording — Task 2 — `grep -rn 'always offered last' tests/` first; only `tests/orient.test.js` is expected.
