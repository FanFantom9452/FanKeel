來源：使用者 2026-10-13 在 TODO 全表盤點的 build 站做 Task 16，在 .fankeel/build/2026-10-13-pane-colour/mockup.html 上用逐塊調整工具新增兩則並送出之後寫的原話：「設計可以更好 就是一開始使用者不會注意到托盤」。同一輪裡使用者被請去「送出」時先回了「送出什麼」，要另外解釋才知道是托盤裡的「全部送出」按鈕。現況：頁面載入後托盤是收起來的，只有右下角一個 fankeel 標誌，點了才展開（assets/tune/overlay.js）。要變成：第一次開頁面的人不必被告知，就看得出這一頁可以點選區塊、從哪裡開始。怎麼做還沒決定，至少三條路：載入時托盤預設展開；標誌旁第一次帶一句提示；標誌本身做得更顯眼。這是要人決定的事，所以放在 Needs a decision。完成條件：使用者選定一條路，tests/tune-overlay.test.js 有一個測試在那個入口被拿掉時轉紅，並由使用者在真機上不經說明開一次頁面、確認自己找得到入口。

2026-10-13 真機：使用者選了「載入時托盤預設展開」（commit 634b3641）。使用者在 http://127.0.0.1:7820/mockup.html 不經說明開頁面，托盤一開就在、點標誌可收合再展開、重新整理後仍展開；被問「一眼看得出從哪裡開始嗎」時回「可以」。
