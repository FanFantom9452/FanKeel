來源：2026-10-12 fankeel 面板 plan（docs/90-agent/plans/2026-10-12-fankeel-pane-band.md）的 Task 6。使用者在 Claude Desktop 用一筆假的 entry 看過上方兩行與 Pane，說其餘的等開新任務時一起測。要看的四件事：一，兩個 session 碰過同一個檔時，兩邊第一行都有 ⚑ 與紅色色帶，Pane 的「其他 session」有一行共用；二，真的 gate 在等時，第二行變成黃底的 gate 在等，Pane 頂端畫出題目與每個選項的完整說明，在 Pane 上按下去後流程往下走（需要 gate.station 開著）；三，終端上的兩行與側邊 Pane，hex 顏色看起來對不對；四，任務開始時 Pane 自己打開，關掉後同一個任務不再跳出來，任務結束時自己關。Claude Desktop 讀的是安裝快照，測之前要先 claude plugin update fankeel@fankeel。做完的標準：四件事各有一句看到了什麼，寫在設計頁 docs/90-agent/plans/2026-10-11-fankeel-pane-design.md 的真機結果底下；看到不對的各開一筆。
