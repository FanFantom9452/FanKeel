# TODO 全表盤點（10-16 下午）：路線圓點、子代理樹、station 按鈕

一句話：路線圓點不再呼吸、改用形狀表示狀態；Pane 多了這個任務派出的子代理樹與一顆打開 station 的按鈕；station-cli 首掃那條偶發失敗修掉，另外三條偶發測試改成 Watch；整套 4301 個快速測試通過。

計畫在 [2026-10-16-todo-patrol-dots-agents.md](../../../99-archive/2026-10-16-todo-patrol-dots-agents.md)，design 在 [同名的 design](../../../99-archive/2026-10-16-todo-patrol-dots-agents-design.md)，station 按鈕依的判斷在 [judgements/2026-10-16-pane-station-link.md](../../judgements/2026-10-16-pane-station-link.md)。

## 起因

使用者開任務時選了 TODO 全表盤點。survey 的關卡上，使用者貼了 band 的截圖：路線圓點為了呼吸動畫多了一圈，他不要動畫，要還沒走到的站是灰色空心、目前這一站是空心加站色外框、走過的站是實心。同一關卡也選了把四條偶發測試一起處理。plan 站中，使用者要 Pane 的 agents 那一塊從只有數量變成一棵樹，列出在跑與跑完的子代理，以及各自的標題、模型和 effort；又用 `/fankeel-ask` 問能不能在 Pane 放一顆常駐、按了會打開 station 網頁的按鈕，並顯示完整網址。判官答可以，使用者在 plan 的關卡上把它加進計畫。

## 做了什麼

- band 與 Pane 的路線圓點：拿掉呼吸的擴散圈，也不再因為一個回合在進行而改畫法。走過的站實心，目前這一站空心、外框用這一站的顏色，還沒到的站灰色空心。band 不再畫成可互動的圖。
- Pane 的 agents：列出這個任務開始之後派出的子代理，最上層最多六個、每個底下最多三個，其餘折成「還有 N 個」。每一列寫在跑或完成、標題、模型、effort 與分鐘。模型與 effort 先讀 Claude Code 自己的子代理檔，讀不到才用標題前綴。
- 新的 hook 在子代理停下時記下時間，子代理被叫回來時再拿掉，所以「完成」會跟著變。幾個子代理同時停下時，紀錄一筆都不會掉。
- Pane 最後一列：station 在跑時是「開啟 station」按鈕加完整網址，按下去用系統的瀏覽器打開；打不開就複製網址，連複製都不行就跳一則提示並附上網址。station 沒在跑時寫「station 未啟動」。
- station-cli 首掃那條測試：會紅的其實是 9 秒的上限，不是 20 秒的逾時，原因是那段時間把 node 自己的啟動也算進去。現在先量一次空跑的啟動時間再扣掉。
- reviewcheck、inject 髒檔、task-worktree 三條偶發測試：今天在沒有其他負載時連跑整套三次都綠，改成 Watch，等整套再紅一次時再查。
- 文件：hook 數從十二改成十三；README 的 hook 清單、profile.md 的 Pane 說明、subagents.md 關於 SubagentStop 的段落、路線圓點的決策頁都改成現在的樣子。
- 七條 Blocked 條目重蓋今天的日期：survey 查過，它們等的事都還沒發生。

八個 task 都各自審過。審查找到的問題修了八輪，每輪都另外審過。其中幾項比較重要：

- 子代理同時停下會互相蓋掉紀錄，改成寫入前先上鎖。
- 子代理檔的讀取原本沒有測試，補上了。
- 按鈕打不開也複製不了時原本什麼都不說，改成跳提示。

verify 的對抗審查推翻一列證據：band 上目前這一站的點就算被改回實心，測試也抓不到。這條退回 build，補上斷言後已確認改回實心時測試會紅。

## 沒做什麼

- 在真的 Claude Desktop 上看：SubagentStop 會不會在子代理停下時觸發、按鈕在 Desktop 上能不能打開瀏覽器、新的圓點與子代理樹看起來對不對。這些都要使用者在真機上看。
- 一個回合在進行的旗標（`turn.running`）現在已經沒有東西拿它來畫，但移除它要動到別的模組與三個測試檔，超出這份計畫，另開一條 TODO。
- 判官建議 station 按鈕先探測網址連不連得上，這次沒做：一筆舊紀錄會畫出按不開的按鈕，按下去由瀏覽器說連不上。
- Ready 的其他條目都要真機或互動式 session，這次沒做。
