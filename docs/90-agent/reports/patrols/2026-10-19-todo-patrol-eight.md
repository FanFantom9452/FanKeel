# TODO 全表盤點（10-19 第二輪）：八個任務做完，七條結案

一句話：盤點後挑出五條「現在就做」，再加上「受控站擋 ask 寫檔」、「stage skill 瘦身」的量測一半與「無人值守」的不做紀錄，共八個任務全部做完；驗證找出 await 的 group 編號會被重編成 1，回到建置修掉、再驗一次後落地。

計畫在 [2026-10-19-todo-patrol-eight.md](../../../99-archive/2026-10-19-todo-patrol-eight.md)。

## 做了什麼

- 子代理遺失或逾時時，等待程式會寫一份失敗交接檔，記下狀況、最後活動與下一步；能自己跑出來的事實不再拿去問人。
- 審查者有三條駁回規則，空的審查也算結果；驗證第二輪的確認者改用另一個模型。
- 設計準則與實作者加上修 bug、效能、重構三種角度；修補到第三輪要先寫下共同前提。
- 狀態列標記的迴圈併成一個小函式，任務區塊沒有計畫時提早結束。
- 卡住的測試五分鐘內變紅並結束，不再佔住整台機器的套件鎖。
- 受控階段裡主控只能寫問題簡報那個資料夾，詢問流程不再被擋。
- 用 input-check 量出每個 stage skill 的大小，並加上位元組上限的測試；瘦身另開一條 TODO。
- 「無人值守時自動回答關卡」決定不做，理由寫成 [決策紀錄](../../../03-decisions/2026-10-19-no-unattended-gate.md)，該條以 abandoned 結案。
