# Task End Implementation Plan

**Goal:** `land` says what shipped and that `/clear` comes after standing down,
and a `SessionStart` hook on `clear` reports the task a wrong order left behind.

**Architecture:** two of the three changes are strings in `lib/stages.js` —
`land.template` gains a `shipped:` block and `land.rules` gains two rules, all of
it inside `land`'s own 494-character headroom because `ALWAYS` has six characters
left. The third is `hooks/carry.js`, a new `SessionStart` hook matched on
`clear` alone: it reads the registry, filters to entries that are `active`, not
live and under twelve hours old, renders one block naming the `adopt` command,
and writes nothing anywhere.

**Tech Stack:** Node's built-in test runner (`node --test`). No dependencies, no
lockfile, no `package.json` `dependencies` key — every import is a `node:`
builtin or a sibling file in this repository.

**Spec:** [docs/plans/2026-08-28-task-end-design.md](2026-08-28-task-end-design.md)

### Step 4 — `renderCarry`

In `lib/render.js`, after `renderResume` and before `RETURN_RULES`:

```js
// The one block that goes out when a session has just been replaced rather than
// continued. `/clear` keeps the process and takes a new session id, so the task
// its predecessor owned is still `active` in the registry with nobody reading
// it — and unlike a compaction, nothing in the new session can tell.
//
// It writes nothing and offers rather than acts. Standing an entry down is the
// user's, and adopting one is a decision, not a tidy-up.
function renderCarry({ orphans, sessionId, now }) {
    if (!Array.isArray(orphans) || !orphans.length || !sessionId) return null;

    const lines = ['FANKEEL — /clear left a task behind, and nothing is reading it now.'];

    for (const orphan of orphans) {
        const data = orphan.data;
        const route = normaliseRoute(data && data.route) || FULL_ROUTE;
        const at = positionIn(route, stageOf(data));
        const claims = claimsOf(data);
        const age = ageText(data, now);

        let where = '  stage: ' + stageOf(data) + (at ? ' (' + at.step + ' of ' + at.steps + ')' : '');
        if (claims.length) where += '  ·  touched ' + claims.length + ' file' + (claims.length === 1 ? '' : 's');
        if (age) where += '  ·  last ' + age + ' ago';

        lines.push('', '  task:  ' + taskOf(data), where);

        const notes = notesOf(data);
        if (notes.length) {
            lines.push('  notes:');
            for (const note of notes) lines.push('    - ' + note);
        }
        const next = nextOf(data);
        if (next) lines.push('  next:  ' + next);

        lines.push('', 'Adopt carries all of it — task, route, claims, notes, next:',
            '  node ' + SCRIPTS.task + ' adopt ' + orphan.sessionId + ' --session ' + sessionId);
    }

    lines.push('', 'Leaving it is fine too; /fankeel → Clear out puts it down without taking it.');
    return lines.join('\n');
}
```

`normaliseRoute`, `positionIn`, `FULL_ROUTE`, `taskOf`, `stageOf`, `claimsOf`,
`notesOf`, `nextOf`, `ageText` and `SCRIPTS` are all already in scope in that
file — `whereLines` at `:76` uses the first four. Add `renderCarry` to the
`module.exports` list at the end.

`notes` are in the block because this is the last place they can be seen: they
die with the task, and a shorter block costs a whole turn of `/fankeel` to
recover what it dropped.

### Step 5 — `hooks/carry.js`

```js
#!/usr/bin/env node
'use strict';

// SessionStart, matcher `clear`. It exists because `/clear` is the one
// continuation that changes the session id.
//
// A resumed or compacted session is the same session and its entry keeps being
// read. `/clear` keeps the process and takes a new id, so `<config>/sessions/
// <pid>.json` is rewritten and the old id leaves the running set: the entry is
// judged dead by every reader at once while staying `active: true`, because
// invariant 2 forbids anything but the user closing a task. Nothing announced
// that, and this is what announces it.
//
// It writes nothing — not the registry, not a badge, not the entry it names.
// Adopting is a decision, and a hook that made it would be the one thing this
// registry is built not to do.

const registry = require('../lib/registry.js');
const live = require('../lib/live.js');
const { renderCarry } = require('../lib/render.js');

// At most three, though in practice there is one: the session that was cleared a
// second ago. More than that is a workspace with several abandoned records in it,
// and listing all of them here would be doing `/fankeel`'s job badly.
const MOST = 3;

function main(raw) {
    let payload;
    try {
        payload = JSON.parse(raw);
    } catch (e) {
        return;
    }
    if (!payload || typeof payload !== 'object') return;

    // A subagent owns no task and must never be offered one. `agent_id` is the
    // discriminator Claude Code names for exactly this — `agent_type` is also
    // set on the main thread of an `--agent` session, which is a real session
    // and does get the offer.
    if (payload.agent_id) return;

    const sessionId = payload.session_id;
    if (typeof sessionId !== 'string' || !sessionId) return;

    const root = registry.rootFor(payload);
    const now = Date.now();
    const state = live.readLive(live.liveConfigDir(), sessionId);

    const orphans = [];
    for (const entry of registry.readActive(root)) {
        if (entry.sessionId === sessionId) continue;
        if (live.isLive(state, entry.sessionId, entry.data.configDir)) continue;
        // Twelve hours is `registry.STALE_MS`, and it is what separates this
        // clear's casualty from a record abandoned last week. The second is
        // `/fankeel` → Clear out's business, not this hook's.
        if (registry.isStale(entry.data, now)) continue;
        orphans.push(entry);
    }
    if (!orphans.length) return;

    orphans.sort((a, b) => (registry.updatedAt(b.data) || 0) - (registry.updatedAt(a.data) || 0));

    const context = renderCarry({ orphans: orphans.slice(0, MOST), sessionId, now });
    if (!context) return;

    process.stdout.write(JSON.stringify({
        hookSpecificOutput: {
            hookEventName: 'SessionStart',
            additionalContext: context,
        },
    }));
}

let input = '';
process.stdin.setEncoding('utf8');
process.stdin.on('data', (chunk) => { input += chunk; });
process.stdin.on('end', () => {
    try {
        main(input);
    } catch (e) {
        // Deliberately silent. This runs before the first prompt of a session,
        // and an error here would be the first thing a new session showed.
    }
});
process.stdin.on('error', () => {});
```
