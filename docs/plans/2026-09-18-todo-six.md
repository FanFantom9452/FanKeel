# TODO 六條一起做 Implementation Plan

**Goal:** 把 TODO 選單四項共六條落地，按它們該落在哪一站分——build 三條、audit 兩條、land 一條。
**Architecture:** build 這一站只做三件事：兩份文件的假敘述更正、一處 SSOT 重述改成連結、`gates` 存下選項文字讓站上的 `swapped` 統計活過 transcript。42 對 pair 與 50 條 stale 記憶留給 `audit`，0.70.0 發版留給 `land`。五個任務，前兩個是文件、後三個是 `gates` 那條鏈。
**Tech Stack:** Node 內建 `node --test`，零相依（`package.json` 完全沒有 `dependencies`）。CommonJS，`'use strict'`，四格縮排。
**Spec:** [2026-09-18-todo-six-design.md](2026-09-18-todo-six-design.md)

## Global Constraints

從專案本身生出來的，不是憑記憶：

- **不准加任何相依。** `package.json` 沒有 `dependencies`，也沒有 `devDependencies`。
  `"test": "node --test"`、`"clean": "node scripts/tmp-clean.js"` 是全部的 script。
- **根目錄沒有 `CLAUDE.md`，也沒有 `AGENTS.md`。** 慣例來自 `CONTRIBUTING.md` 與程式本身。
- **`lib/*.js` 第一行是 `'use strict';`，縮排四格**（`lib/gates.js:1`）。
- **`lib/gates.js:14-15` 已有 `MAX_GATES = 60` 與 `PICK_LEN = 120`。** 沿用，不新增常數。
- **`tests/version.test.js:99-103` 釘死版號正好 13 處且全部同一字串。** 改動不得讓它變數量。
- **`node --test` 的 spec reporter 印 `✔`／`✖` 與 `ℹ pass`／`ℹ fail`，沒有 TAP 的 `ok` 行。**
  想抓結果就抓 `ℹ pass`／`ℹ fail`，grep `ok` 永遠是空的。
- **`.fankeel/map.md` 的 filing：** `docs` 是 reference、`docs/decisions` 是 decision、
  `docs/plans` 是 plan、`docs/reports` 與 `docs/judgements` 是 report、`docs/archive` 是
  archive、`skills`／`agents`／`.claude/agents` 是 reference、`evals` 是 fixture。
- **兩頁是 design-intent，不得當成已存在來引用：** `docs/improvement-brief.md`、
  `docs/plans/2026-09-09-design-class-prompt.md`。
- **更正慣例（`skills/fankeel-audit/SKILL.md:114-118`）：** 寫錯的條目加一行
  `**Corrected YYYY-MM-DD:**` 說明錯在哪，**永不靜默改寫**；刪除只刪使用者指名的。
- **`node scripts/docs-check.js` 與 `node scripts/todo-check.js` 兩支都必須保持綠。**
- **commit 標題是英文類型前綴加中文主旨**（`docs:`、`fix:`、`feat:`）。
- **每一次派工的 brief 都要寫「用 `function(){}`，不要箭頭函式」。** 裝著的 0.69.0
  副本沒有 `f466f06` 修好的 guard 箭頭誤判，唯讀 subagent 的 Bash 會把 `=>` 當成
  redirect 擋掉。0.70.0 在 `land` 發版之前，這一句每次都要帶——這條約束到發版為止。

開工前先跑一次 `npm test` 拿基準線——設計的「還沒查的」那一節就是為這個留的，這一輪到
現在都還沒跑過完整套件。

```js
            const events = s.detail && Array.isArray(s.detail.events) ? s.detail.events : [];
            const rows = [];
            for (const e of events) {
                if (e.kind !== 'gate' || !Array.isArray(e.qs)) continue;
                for (const q of e.qs) {
                    rows.push({ first: Array.isArray(q.labels) ? q.labels[0] : null, picked: q.a });
                }
            }
            // `detail` needs the transcript. When it is gone the entry's own
            // `gates` still has the wording, which is why Task 3 put it there:
            // without this the `swapped` denominator quietly shrinks as
            // transcripts age, and the page cannot show that it did.
            if (!rows.length) {
                for (const g of Array.isArray(s.gates) ? s.gates : []) {
                    rows.push({ first: Array.isArray(g.labels) ? g.labels[0] : null, picked: g.picked });
                }
            }
            for (const r of rows) {
                if (typeof r.first !== 'string' || r.first === '' || r.picked === null) continue;
                total.set(r.first, (total.get(r.first) || 0) + 1);
                if (r.picked !== r.first) lost.set(r.first, (lost.get(r.first) || 0) + 1);
            }
```
