派送方式：多個 Agent 與 Workflow（示意）

多個 Agent

主控坐鎮、一份一份收

主控 派 收 提交 收 提交 收 提交 實作者 A 實作 實作者 B 實作 實作者 C 實作 重派 實作 reviewer 審 審 審
  • 每份回傳都進主控 context，逐份讀
  • 回來一個提交一個
  • 能插手：衝突就重派、怪就停

Workflow

整組打包丟出去、只收彙總

主控 開 彙總 提交 任務 1 實作 審 任務 2 實作 審 任務 3 實作 審 腳本 implement → review，中間產物留在腳本裡
  • 腳本內每任務一條 implement→review，不等別人
  • 只回彙總，省主控 context
  • 跑完前不提交，也不回主控、停不了

依賴深度決定分幾組

白板任務

一條依賴鏈：平行機制都在，依賴決定它用不上。

盤點任務

每格一組；同一深度的任務彼此不衝突，可一起跑。
