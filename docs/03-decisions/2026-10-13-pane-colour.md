# Pane 的配色改成安靜版，多一行 route，拿掉兩塊（10-13）

一句話：右邊的 Pane 不再每一塊一個顏色，標題與色條共用同一個灰，顏色只留給狀態與警示；任務標題下面多一行寫出站名的 route；「這個 session」與「用量額度」兩塊拿掉。

這改掉 [10-12 面板的決定](2026-10-12-fankeel-panel.md)之後那一輪設計裡「每塊各有一個固定顏色」與「Pane 顯示用量額度、guard 說明」的部分；輸入框上方的兩行沒有動。

## 決定

- 任務標題與 `next:` 的下面多一行 route：把這個任務會走的站名用 ` › ` 連起來，例如 `survey › design › build › verify › land`。走完的站是綠色，目前這一站是粗體、用終端自己的顏色，還沒到的站與分隔符是灰色。欄位太窄時在站與站之間換行。
- `tasks`、`context`、`notes` 三塊的標題與色條共用同一個灰（`#8a8a8a`）。gate 維持琥珀色，撞檔維持紅色，最下面那一列維持暗色。
- tasks 清單裡每個 task 的記號顏色不變：完成是綠、agent 出去是紫、輪到你是琥珀、還沒做是灰。
- 「這個 session」一塊拿掉。它原本說明 `guard` 的設定，以及這個任務改過幾個檔。
- 「用量額度」一塊拿掉。它原本顯示 5 小時與 7 天兩個額度各在多久後重置。
- 空間不夠時，先讓出 notes，再讓出 tasks 的清單（標題那一列留著）。

## 為什麼

- 使用者想在 Pane 上看到帶站名的 route，而且三種站要分得出來。輸入框上方只有圓點，沒有站名。
- 使用者看了三種配色的比較頁後選了安靜版。每塊一色時，平常就有五六種顏色同時在畫面上，gate 與撞檔出現時反而不顯眼。
- 「跟著站色」那一版在 `survey`、`design` 兩站太暗，深色底上的對比只有 3 左右。
- 兩塊被拿掉，是使用者看過清單後自己選的。

## 放棄了什麼

- 畫面上不再有任何地方顯示 5 小時與 7 天的額度何時重置。上方兩行本來就不畫，現在 Pane 也不畫了。
- 不能再靠顏色分辨 `tasks`、`context`、`notes` 是哪一塊，要讀標題。
- 這組顏色沒有一個在深色底與淺色底上都達到 4.5 的對比。
- 改完後還沒有在真機上看過；比較頁是用等寬字重畫的示意，不是 Pane 本身。
- gate 與任務標題的上下順序沒有動，仍然是任務在上。
