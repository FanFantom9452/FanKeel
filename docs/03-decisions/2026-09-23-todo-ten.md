## 三、各階段抓到的

- build：`tests/inject.test.js` 的模擬站沒帶 fingerprint，新的 `ensureServe` 判它舊程式而 kill 了測試程序本身（43/43 過、檔案 exit 1）；`render.js` 手拼 `file://`；`design.skill` 設定分支漏掉 `.fankeel/build/`；整條分支 review 抓到 Task 6／11 在 `lib/` 的插入讓 `docs/90-agent/reference/subagents.md` 六條行號位移——兩個 task 各自的 diff 都不碰那頁。
- verify：`render.js` 在明確傳入相對 `--out` 時不寫 PNG 卻 exit 0（我當時說成「預設用法也壞」，說重了，預設本來就是絕對路徑）；`wa kid` 子列沒有測試；三處文件變假。adversary 兩輪各推翻一次「證據沒落檔」的列，重跑落成 log 才算。
- audit：`registry.md` 與 `station.md` 對 `stale` 的用法相反；`subagents.md` 把 `agentId` 寫成必填；`probe()` 多了一個無人傳的參數；`render.js` 手寫參數解析。
