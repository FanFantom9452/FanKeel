# Station 儀表板：頁標題取代麵包屑，編輯模式取代勾選面板（10-16）

一句話：station 頂列改寫目前這一頁的標題，不再畫麵包屑；卡片的排序、隱藏與新增改在卡片區裡的編輯模式做，原本的「調整卡片」勾選面板拿掉，另有八種預設不開的卡片可從「新增卡片」加入。

## 決定

- 頂列：品牌只留標誌與 `fankeel`；`pageTitle(r)` 給目前這一頁的標題，只有一個子頁的群組用群組名稱；serve 狀態只剩圖示（`serveIconHtml`），文字放在 `title` 與 `aria-label`。
- 卡片由 `dashKinds()` 這張表登記，每種是 `{name, hint, side, def, render}`；順序與隱藏照舊存在 `station.dash`（`{order, off}`）。
- 編輯模式（`view.dashEdit`）：拖曳把手、隱藏／顯示、還原預設、完成；Esc 或換頁都會結束。
- 「可以開工」的專案列先開 `<dialog>`，分 Ready、Blocked、Watch、Done 四頁，有 Decision 時多一頁；Ctrl 或中鍵照舊開新分頁。
- 有對話框開著時，1–4 的 gate 快捷鍵不作用。

## 為什麼

使用者核准的 mockup（r-0047）就是這個樣子：麵包屑跟左側選單重複，勾選面板離卡片太遠，看不出改了哪張。在卡片原地編輯，改的東西就在眼前。

新卡片都用頁面已經收到的資料畫，不必讓 server 多送任何東西。

## 放棄了什麼

- 保留麵包屑當次要導覽：左側選單已經標出目前位置，兩處說同一件事。
- 八張新卡預設就開：儀表板會擠滿使用者沒要的東西，改成從「新增卡片」自己加入。
- 卡片自己挑放哪一欄：每種卡片的欄位由 `dashKinds()` 的 `side` 固定。
