# promo30 30 秒解說片（09-29）：決策紀錄

一句話：導覽引擎多了第二條 timeline `promo30`——30 秒、1800 格的龍骨造船解說片，給開發者看，中英兩版；頁面與錄影腳本都改成播 hash 指名的那一條，第一版 60 秒 reel 一格未動。

design 見 [../99-archive/2026-09-29-promo30-design.md](../99-archive/2026-09-29-promo30-design.md)，計畫見 [../99-archive/2026-09-29-promo30.md](../99-archive/2026-09-29-promo30.md)，引擎與錄影的說明見 [../90-agent/reference/station.md](../90-agent/reference/station.md)。

## 定了什麼

- 第一版 reel 先存成 v1：tag `tour-reel-v1`、MP4 複製到 `F:/ymlab/fankeel-videos/v1/`；第二版 tag `tour-reel-v2`、MP4 在 `F:/ymlab/fankeel-videos/v2/`（survey 與 build 的 gate，使用者答）。
- 概念從「龍飛來、捲曲、只剩骨頭」改成龍骨造船：龍的 spike 畫不好看，使用者從多個方案裡選了造船（design，使用者答）。
- 每個 stage 用真的元件表示——語言與檔案圖示、mockup 逐塊調整、audit 劃掉過期文件並把 plan 收進封存資料夾、land 收 worktree——不要全是文字（design，使用者依參考影片提）。
- 檔名 `assets/station/tour-keel.js`，不是 plan 寫的 `tour-promo30.js`：`scripts/station.js` 的靜態路由只放行 `tour(?:-[a-z]+)*`，而另一個 session 正佔著 `station.js`（build 的 gate，使用者答）。封存的 plan 與 design 保留舊名，當歷史。
- 配樂 `render(cues, frames)` 的長度跟著 timeline；reel 的配樂逐樣本不變。

## 量到什麼

- 全套 `npm test`：2424 過、0 失敗；`docs-check` 全部解析。
- 兩支 v2 影片各 1800 格、30 秒 AAC；zh 版 7 個 stage 抽格的點數都對，en 版沒抽（verify 記為沒查）。
- reel 配樂新舊渲染比對 2646000 個樣本 0 差異；兩個變異測試轉紅。

## 在哪裡回頭

- 使用者看完 v2：風格喜歡、右側動畫好，但左側直接畫一艘船太直白，也讓左邊顯得沒用——「還可以，但沒有戳到點」。下一步是 v3 的 design，從使用者自己說的重點出發，重做左側。
- 後段 U 形肋骨弧線糾結、小 logo 像梳子——TODO 的 `station-4`、`station-5`。

## v3

- v3 重做左側為蜂巢環（honeycomb ring），程式在 `assets/station/tour-ring.js`；字幕沿用 v1。
- v2 一格未動，v2 的 hash 由 `tests/tour-promo30v3.test.js` 釘住。
- 影片在 `F:/ymlab/fankeel-videos/v3/`：`promo30v3-zh.mp4`、`promo30v3-en.mp4`，各 1800 格、30 秒、AAC。
- 全套 `npm test`：2473 過、0 失敗（16e69701）。

## v4

- v4 把片長放慢到 60 秒（3600 格）：hook 300、route 240、七個 stage 各 360、outro 540；v3 的節奏保留、重新配時，動作速度不變（使用者答：新做 `promo30v4`、大計數加進度軌、把多的 30 秒拿來停留）。
- 每個 stage 先有 60 格仿 v1 的進場（色塊淹入、大的 `0N / 07`、stage 名），之後環的下方留一列：計數、stage 名與 7 點進度軌，已完成的點用該 stage 的顏色、目前的點脈動、未到的點空心，已完成點數等於環上填滿的格數。
- 程式仍在 `assets/station/tour-ring.js`；`tour.html#promo30v4@<格>` 播放，`node scripts/tour-record.js promo30v4 [--lang zh|en]` 錄影，MP4 不是 3600 格與 60 秒音訊就 exit 1。影片預定放 `F:/ymlab/fankeel-videos/v4/`。
- v2、v3 仍逐格不變。

## v5

- v5 是 74 秒（4440 格）的導覽片，照核准的 styleframe 畫：hook 0–11 秒（一個通用專案的檔案樹長大、grep 漏檔）、intro、七個 stage、outro 到 74 秒。stage 從 14、20、26、32、42、50、60 秒起，survey／design／plan／land 各 6 秒、build 與 audit 各 10 秒、verify 8 秒，outro 66–74 秒。
- 左上一條標頭（字形、字標、`0N / 07`、stage 名）取代進度軌、pills、狀態列與左邊的大字形；字幕只留置中的一行。
- 檔案圖示用 Material Icon Theme 5.38.1（MIT），放在 `assets/station/icons/` 並附 `LICENSE.txt`，以 data URI 內嵌；播放器等 `TOUR_PROMO30V5.ready` 才畫第一格。
- `tour.html#promo30v5@<格>` 播放，`node scripts/tour-record.js promo30v5 [--lang zh|en]` 錄影，只留 MP4（wav 會刪），預設放 `F:/ymlab/fankeel-videos/v5/`（`FANKEEL_VIDEOS_V5` 與 `--out` 可改）。
- v2、v3、v4 仍逐格不變。
